## 🛠️ Key Technologies Covered
- **Core Backend**: Python 3.12+, FastAPI, Pydantic V2, Asynchronous I/O (`asyncio`)
- **Databases & ORM**: PostgreSQL 16, Async SQLAlchemy 2.0, Alembic migrations, `asyncpg`
- **Containerization & CI/CD**: Docker, Docker Compose, GitHub Actions, Poetry / `uv`, Ruff, Mypy, Pytest
- **Generative AI & LLMs**: OpenAI (GPT-4o), Anthropic (Claude 3.5 Sonnet), Google Gemini, Local LLMs (Ollama)
- **Vector Storage & RAG**: PostgreSQL `pgvector`, ChromaDB, HNSW / IVFFlat indexing, Hybrid Search (Dense + BM25), Cross-Encoder Rerankers
- **Agentic Orchestration**: LangChain (LCEL), LangGraph stateful cyclic graphs, Checkpointing memory, Human-in-the-loop (HITL)
- **Model Context Protocol (MCP)**: Custom Python MCP Servers & Clients (Anthropic MCP standard)
- **Evaluation & Security**: RAGAS, TruLens, Prompt Injection Guardrails, NeMo Guardrails, LangSmith tracing

**Enterprise Autonomous Knowledge Assistant & Multi-Agent Operations Platform**:
- Multi-tenant async FastAPI backend with OAuth2 JWT security.

- Collaborative LangGraph multi-agent team (Router, Research, SQL Analytics, Fact Verification).
- Custom MCP servers connecting AI models safely to internal databases and external APIs.
