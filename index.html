Detailed Syllabus

Module-by-Module In-Depth Curriculum

Explore the complete objectives, syllabus breakdown, and hands-on assignments for all 15 modules.

Module - 1

Python Core & Advanced Object-Oriented Programming (OOP)

Objective

Understand Python 3.12+ features, memory management, and OOP principles. Master dunder protocols, custom exceptions, decorators, generators, and async concurrency with asyncio.

Course Outline

  • Python Ecosystem: Virtual environments, memory model, garbage collection
  • Data Structures: Lists, Tuples, Dicts, Sets, and collections module
  • OOP 4 Pillars: Encapsulation, Inheritance, Polymorphism, Abstraction
  • Dunder Protocols: __init__, __str__, __repr__, __eq__, __enter__
  • Advanced: Closures, Function Decorators, Generators, Context Managers
  • Concurrency: Event loop, Coroutines, asyncio.gather(), GIL

Real-World Assignments

Virtual Banking ATM Engine: Implement an OOP banking system with custom exception hierarchy (InsufficientFundsException) and audit logging.
Layered Book Inventory Manager: Build a layered library app (Service, Repository) using generators for chunked inventory processing.
Concurrent Async Web Pinger: Create an asyncio script concurrently pinging 50+ endpoints, logging latency metrics to JSON.
Module - 2

Relational Databases & PostgreSQL

Objective

Understand relational database design, normalization (1NF–3NF), complex joins, subqueries, analytical window functions, indexing, and JSONB storage in PostgreSQL 16.

Course Outline

  • Database Design: Primary keys, Foreign keys, Cascade rules, Constraints
  • SQL CRUD: INSERT ... RETURNING, Aggregations, Grouping
  • Joins: Inner, Left, Right, Full, Cross, and Self-Joins
  • Subqueries & CTEs: Correlated queries and WITH RECURSIVE
  • Window Functions: ROW_NUMBER(), RANK(), LEAD(), LAG()
  • Performance: B-Tree & GIN Indexes, EXPLAIN ANALYZE, ACID locking

Real-World Assignments

E-Commerce Schema Design: Architect a normalized database for Users, Products, Orders, and Payments with audit timestamps.
Advanced Salary & Sales Analytics: Write window functions identifying top 3 spending customers monthly and employees earning above dept managers.
JSONB Document Store: Store unstructured delivery tracking metadata in JSONB columns with fast indexing and sub-key filtering.
Module - 3

Database Integration & Async SQLAlchemy 2.0 ORM

Objective

Master SQLAlchemy 2.0 modern declarative mapping, asynchronous engines with asyncpg, association mappings (1:1, 1:N, M:N), and Alembic migrations.

Course Outline

  • Async DB Engines: create_async_engine and async_sessionmaker
  • Modern Mapped Syntax: Mapped[...] and mapped_column()
  • Relationships: One-to-Many, Many-to-Many association tables, Cascades
  • Query Optimization: Avoiding N+1 queries with selectinload and joinedload
  • Database Migrations: Alembic auto-generation, revisions, and rollbacks

Real-World Assignments

Async Product Catalog ORM: Build an asynchronous Python program modeling Categories, Products, and Tags (M:N) using asyncpg.
Alembic Migration Suite: Create tables, alter columns safely, and execute rollback tests without data loss.
N+1 Query Optimizer: Benchmark and eliminate 100+ nested queries into a single query using selectinload.
Module - 4

Git, GitHub & Modern Python Tooling (uv / Poetry)

Objective

Understand distributed version control, branching strategies, conflict resolution, modern Python project packaging with poetry / uv, and CI pipelines with GitHub Actions.

Course Outline

  • Git Internals: Working tree, Staging, Local/Remote repos
  • Branching & Workflows: Feature branching, Merge vs Rebase
  • Conflict Resolution: Detecting, rebasing, and resolving conflicts cleanly
  • Modern Tooling: pyproject.toml, Poetry & uv (Rust-based manager)
  • Code Quality: Automated linting with Ruff, Mypy typing, and Pre-commit
  • GitHub Actions: Continuous Integration (CI) configuration

Real-World Assignments

Team Conflict Resolution: Simulate a Git branch conflict; resolve cleanly with interactive rebase and verified history.
Enterprise Repo Setup with Pre-commit: Configure a repository with Poetry/uv, strict Ruff lint rules, and Git pre-commit hooks.
Automated CI Action: Build a GitHub Actions YAML workflow that runs automated tests on every pull request.
Module - 5

Testing with Pytest & Mocking Frameworks

Objective

Master test-driven development (TDD), Pytest fixtures, parametrization, and mocking external services/databases using unittest.mock and pytest-mock.

Course Outline

  • Pytest Fundamentals: Test discovery, assertions, execution flags
  • Advanced Fixtures: @pytest.fixture scopes (function, module, session)
  • Parametrized Testing: @pytest.mark.parametrize for edge cases
  • Mocking: Mock, MagicMock, AsyncMock, and monkeypatching
  • Async Tests: Testing coroutines with pytest-asyncio
  • Coverage: Generating HTML reports and enforcing >85% coverage gates

Real-World Assignments

Financial Logic Parametrized Suite: Build a unit test suite testing complex financial tax calculators across multi-tier tax brackets.
Database Session Fixture: Create a session-scoped in-memory SQLite fixture that wipes tables cleanly between test cases.
Mocking External Payment Gateway: Write unit tests verifying that Stripe API timeouts and failures trigger appropriate retries.
Module - 6

FastAPI Framework & Pydantic V2

Objective

Understand ASGI architecture, Pydantic V2 validation, routing, path/query parameters, and FastAPI's powerful Dependency Injection system.

Course Outline

  • ASGI Foundations: WSGI vs ASGI, Uvicorn worker process model
  • Pydantic V2: BaseModel, Field, field_validator, model_validator
  • Endpoint Operations: GET, POST, PUT, DELETE, PATCH, status codes
  • Dependency Injection: Depends(), reusable dependencies, dependency trees
  • OpenAPI Documentation: Interactive Swagger UI (/docs) and ReDoc

Real-World Assignments

User Registration API: Build an endpoint validating password strength and email domains via Pydantic V2 validators.
Product Filter Endpoints: Implement pagination (offset/limit) and sorting dependencies applied across endpoints.
API Key Dependency: Build a reusable dependency verifying custom X-API-KEY headers before invoking route handlers.
Module - 7

Enterprise REST API Architecture with FastAPI

Objective

Architect enterprise-scale applications using Layered Architecture (Routers, Services, Repositories), centralized error handling, and background tasks.

Course Outline

  • Clean Architecture: Structuring api/, services/, repositories/
  • Modular Routing: Organizing multi-file endpoints using APIRouter
  • Session Lifecycle: Managing async DB transactions in request lifespans
  • Centralized Exceptions: Global exception handlers and error JSON envelopes
  • Non-blocking Tasks: Using BackgroundTasks for email and notifications
  • Middleware: CORS configuration, request timing, and request ID tracing

Real-World Assignments

E-Commerce Order Microservice: Build a cleanly layered order service isolating business rules from DB queries.
Global Error Interceptor: Intercept PostgreSQL unique constraint violations, returning HTTP 409 error envelopes.
Background Receipt Worker: Dispatch background receipt generation tasks after order placement without latency spikes.
Module - 8

API Security, Authentication & Role-Based Access Control

Objective

Implement secure authentication with OAuth2 Password Bearer flow, signed JSON Web Tokens (JWT), password hashing with Bcrypt, and Role-Based Access Control (RBAC).

Course Outline

  • Password Security: Salting and hashing with Passlib and Bcrypt
  • JWT Tokens: Claims, expiration, symmetric vs asymmetric signing
  • OAuth2 Flow: OAuth2PasswordBearer and protected endpoints
  • Token Refresh: Access token + refresh token rotation strategy
  • RBAC: Role-checker dependency factories (Admin, Manager, User)
  • Rate Limiting: Protecting endpoints against abuse using SlowAPI

Real-World Assignments

JWT Auth Service: Build registration and login issuing signed JWT tokens with /me verification endpoint.
Role-Protected Healthcare Portal: Implement endpoints enforcing distinct access rules for Doctors, Nurses, and Patients.
Redis Rate Limiter: Enforce a limit of 5 login attempts per minute per IP address with HTTP 429 responses.

Docker, Containerization & Microservice Deployment

Objective

Understand containerization concepts, write optimized multi-stage Dockerfiles for Python/FastAPI, and orchestrate multi-container stacks with Docker Compose.

Course Outline

  • Container Fundamentals: Images, Layers, Registries, Unprivileged users
  • Multi-Stage Builds: Caching layers, eliminating build artifacts (<150MB)
  • Docker Compose: Orchestrating FastAPI, PostgreSQL, and Redis services
  • Networking & Volumes: Persistent DB storage and isolated bridge networks
  • Healthchecks & Dependencies: depends_on with healthcheck conditions

Real-World Assignments

Optimized Multi-Stage Dockerfile: Package a production FastAPI app in an unprivileged, minimal Alpine/slim image.
Multi-Service Compose Stack: Launch FastAPI, PostgreSQL, and pgAdmin with persistent volumes in one command.
Self-Healing Healthcheck Setup: Add healthchecks ensuring API traffic waits until PostgreSQL is ready.
Module - 10

LLM Fundamentals, Prompt Engineering & Provider APIs

Objective

Understand LLM architectures, tokenization, prompt engineering (CoT, ReAct), provider APIs (OpenAI, Claude, Gemini), local models via Ollama, and structured Pydantic outputs.

Course Outline

  • LLM Mechanics: Next-token prediction, Transformers, Context windows
  • Prompt Engineering: Zero-shot, Few-shot, Chain-of-Thought (CoT)
  • Provider SDKs: OpenAI GPT-4o, Anthropic Claude 3.5, Google Gemini
  • Local LLMs: Running open-weights (Llama 3, Mistral) via Ollama locally
  • Structured Outputs: Enforcing JSON adhering directly to Pydantic models

Real-World Assignments

Multi-Provider Failover Client: Build an LLM client that automatically falls back to Claude or Gemini on OpenAI rate limits.
Structured Resume Extraction API: Extract raw resume text into typed Pydantic models with validated experience arrays.
Privacy-First Local Classifier: Run a local Llama 3 model via Ollama to categorize sensitive tickets without cloud transmission.
Module - 11

Vector Embeddings & Vector Databases (pgvector & Chroma)

Objective

Understand semantic vector spaces and distance metrics. Store and query embeddings in PostgreSQL using the pgvector extension with HNSW & IVFFlat indexes, and prototype with ChromaDB.

Course Outline

  • Dense vs Sparse Embeddings: High-dimensional semantic representations
  • Distance Metrics: Cosine Similarity, Euclidean Distance (L2), Dot Product
  • PostgreSQL pgvector: Vector data types, similarity operators (<=>)
  • Vector Indexing: HNSW vs IVFFlat index construction and query tuning
  • Specialized Vector Stores: Local and persistent ChromaDB collections

Real-World Assignments

Semantic FAQ Search Engine: Ingest 50 company policy documents into ChromaDB with top-3 similarity search.
Product Semantic Search in PostgreSQL: Extend product tables with vector columns; query semantic matches via SQL.
HNSW Index Benchmark: Ingest 10,000 vectors; benchmark speed and recall trade-offs before and after HNSW indexing.
Module - 12

Advanced Retrieval-Augmented Generation (RAG)

Objective

Overcome naive RAG failure modes. Master semantic document chunking, Hybrid Search (Dense + BM25 keyword), Cross-Encoder reranking, and grounded answers with source citations.

Course Outline

  • RAG Stages: Ingestion, Retrieval, Generation — Naive vs Enterprise RAG
  • Chunking Strategies: Recursive character vs Semantic chunking
  • Hybrid Search: Combining Dense Vectors with BM25 via Reciprocal Rank Fusion
  • Reranking: Scoring question-passage relevance with Cross-Encoder models
  • Grounded Generation: Prompt constraints, citation generation, and refusal triggers

Real-World Assignments

Technical Manual Q&A System: Ingest a 50-page complex technical PDF, chunk recursively, and answer queries with citations.
Hybrid Search Engine: Implement RRF combining BM25 keyword matching with dense vectors for exact part number lookups.
Cross-Encoder Reranker Filter: Retrieve top-20 candidates and rerank with a Cross-Encoder to feed only top-3 snippets to the LLM.
Module - 13

LangChain & LangGraph Stateful Agent Orchestration

Objective

Master LangChain Expression Language (LCEL) and stateful, cyclic multi-agent graphs with LangGraph, including persistent memory checkpointers and human-in-the-loop workflows.

Course Outline

  • LangChain Core: Runnables, PromptTemplates, OutputParsers, LCEL syntax
  • LangGraph Fundamentals: State definitions, Nodes, Edges, StateGraph
  • Cyclic Loops: Reasoning loops with conditional edges and recursion limits
  • Memory & Checkpointing: Thread-level persistence with SQLite/Postgres checkpointers
  • Human-in-the-Loop (HITL): Pausing execution for human approval before writes

Real-World Assignments

LCEL Review Summarizer: Build an LCEL pipeline parsing reviews into sentiment metrics and structured action items.
LangGraph Fact-Checking Loop: Build a graph where a Researcher Node searches and a Grader Node loops until verified.
HITL Refund Approval Agent: Build a customer refund agent that pauses and requests human manager confirmation for amounts >$100.

  • Model Context Protocol (MCP): Open standard architecture, Host, Client, Server

  • Custom Python MCP Server: Exposing database and API tools over stdio/SSE
  • Multi-Agent Architecture: Supervisor-worker multi-agent teams

Real-World Assignments

Safe SQL Exploration Agent: Build an agent that inspects database schemas and queries tables while blocking destructive queries.
Enterprise Database MCP Server: Build a custom Python MCP server exposing company inventory tools tested with Claude.
Multi-Agent Coder & Reviewer: Build a team where a developer agent writes code and a reviewer agent validates via MCP tools.
