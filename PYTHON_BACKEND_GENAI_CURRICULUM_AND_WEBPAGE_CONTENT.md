### Title: **Enterprise Autonomous Knowledge Assistant & Multi-Agent Operations Platform**

#### Architecture Overview:
An end-to-end, production-grade enterprise system featuring a high-performance **FastAPI** backend, **PostgreSQL + pgvector** storage, **LangGraph** multi-agent coordination, and **Model Context Protocol (MCP)** tool integrations.

3. **Hybrid RAG Pipeline**: Ingests enterprise PDFs, markdown documentation, and audio transcripts. Uses recursive chunking, dense vector similarity combined with BM25 full-text search, and cross-encoder reranking.
4. **LangGraph Multi-Agent Team**:
   - *Triage & Router Agent*: Classifies user intent and routes queries.
   - *Deep Research Agent*: Recursively searches internal vector storage and external web APIs.
   - *SQL Analytics Agent*: Queries relational databases using natural language to SQL generation with safety guards.

5. **Model Context Protocol (MCP)**: Custom MCP server exposing enterprise databases, Jira/GitHub integrations, and internal CRM tools directly to the agent.
6. **Streaming & Client Integration**: Real-time token streaming via Server-Sent Events (SSE) consumed by a modern frontend dashboard.
7. **Automated Evaluation & Observability**: Continuous RAG evaluation pipeline with RAGAS (Faithfulness, Answer Relevancy, Context Recall) and full execution tracing via LangSmith.
8. **DevOps & Cloud Packaging**: Multi-container Docker Compose setup with Redis caching, Nginx reverse proxy, automated database migrations, and healthcheck monitors.

### Module - 1: Python Core & Advanced Object-Oriented Programming (OOP)

#### Objective:
- Understand modern Python 3.12+ features, memory model, and typing ecosystem.
- Master Object-Oriented Programming (OOP) principles, design patterns, and dunder protocols.
- Learn robust exception handling, custom hierarchy, and context managers.
- Develop asynchronous concurrent scripts using `asyncio` for high-throughput I/O.
- Build maintainable Python applications using clean, layered architecture.

#### Course Outline:
- **Python Ecosystem & Setup**: Virtual environments, interpreter internals, garbage collection, and dynamic typing.
- **Deep Dive into Data Structures**: Lists, Tuples, Dictionaries, Sets, `collections` (`namedtuple`, `defaultdict`, `Counter`, `deque`).
- **Object-Oriented Programming (OOP)**:
  - Classes, Instances, Class Attributes vs Instance Attributes.
  - The Four Pillars: Encapsulation (name mangling, properties), Inheritance (Single, Multiple, MRO, `super()`), Polymorphism, and Abstraction (`abc.ABC`, `@abstractmethod`).
  - Dunder (Magic) Methods: `__init__`, `__str__`, `__repr__`, `__eq__`, `__hash__`, `__len__`, `__getitem__`, `__enter__`, `__exit__`.
- **Advanced Python Concepts**:
  - First-class functions, Closures, and Function Decorators (with and without arguments).
  - Iterators, Iterables, and Generators (`yield`, `yield from`, memory optimization).
  - Custom Context Managers using class protocol and `@contextlib.contextmanager`.
  - Type Hints, Generics, and Static Analysis with Python `typing` module (`Union`, `Optional`, `TypeVar`, `Protocol`).
- **Modern Concurrency**:
  - Threading vs Multiprocessing vs Asynchronous I/O.
  - Python Global Interpreter Lock (GIL) and free-threaded Python updates.
  - Event loop, Coroutines, Tasks, `asyncio.gather()`, `asyncio.create_task()`, async context managers.

#### Assignments:

### Module - 2: Relational Databases & PostgreSQL

#### Objective:
- Understand relational database concepts, relational modeling, and normalization (1NF, 2NF, 3NF).
- Perform data definition (DDL), manipulation (DML), and query operations (DQL) with PostgreSQL 16.
- Write complex queries using multi-table joins, subqueries, CTEs, and analytical window functions.
- Optimize database performance using indexing strategies (B-Tree, GIN, GiST), `EXPLAIN ANALYZE`, and ACID transactions.

#### Course Outline:
- **Relational Concepts**: Tables, schemas, primary keys, foreign keys, cascade rules, constraints (`CHECK`, `UNIQUE`, `NOT NULL`).
- **PostgreSQL Setup & Tools**: pgAdmin, psql CLI, connection strings, data types (UUID, TIMESTAMP, JSONB, ARRAY).
- **Core SQL Operations**:
  - CRUD operations: `INSERT ... RETURNING`, `UPDATE`, `DELETE`, bulk inserts.
  - Filtering, Sorting, Aggregations (`GROUP BY`, `HAVING`, aggregate functions).
- **Advanced Querying**:
  - Multi-table Joins: `INNER JOIN`, `LEFT OUTER JOIN`, `RIGHT OUTER JOIN`, `FULL OUTER JOIN`, `CROSS JOIN`, `SELF JOIN`.
  - Subqueries (correlated vs non-correlated, `EXISTS`, `IN`, `ANY`, `ALL`).
  - Common Table Expressions (CTEs) & Recursive CTEs (`WITH RECURSIVE`).
  - Analytical Window Functions: `ROW_NUMBER()`, `RANK()`, `DENSE_RANK()`, `LEAD()`, `LAG()`, `OVER(PARTITION BY ... ORDER BY ...)`.
- **PostgreSQL Advanced Capabilities**:
  - Semi-structured data with `JSONB` querying and operators (`->`, `->>`, `@>`).
  - Indexing: B-Tree, GIN index for JSONB, Index overhead vs Query speed.
  - Transactions & Concurrency: `BEGIN`, `COMMIT`, `ROLLBACK`, Isolation levels, Pessimistic vs Optimistic Locking (`SELECT FOR UPDATE`).

### Module - 3: Database Integration & Async SQLAlchemy 2.0 ORM

#### Objective:
- Understand Object-Relational Mapping (ORM) and the transition from raw DB drivers to modern ORMs.
- Master SQLAlchemy 2.0 modern declarative mapping syntax and async engines (`asyncpg`).
- Establish robust association mappings (One-to-One, One-to-Many, Many-to-Many).
- Implement database migrations and version control using Alembic.
- Prevent common ORM pitfalls (N+1 queries, detached instances, connection leaks).

#### Course Outline:
- **DB Drivers vs ORM**: Python DBAPI (`psycopg3`, `asyncpg`), Connection strings, and connection pooling concepts.
- **SQLAlchemy 2.0 Architecture**:
  - Core vs ORM in SQLAlchemy 2.0.
  - `create_async_engine`, `async_sessionmaker`, and asynchronous context managers.
- **Declarative Models & Relationships**:
  - `Mapped` and `mapped_column` type annotations.
  - One-to-One relationships with `uselist=False`.
  - One-to-Many and Many-to-One relationships with `relationship()` and `ForeignKey`.
  - Many-to-Many relationships using explicit Association Tables and Association Objects.
  - Cascade deletes and relationship loading strategies (`selectinload`, `joinedload` to prevent N+1 issues).
- **Querying with SQLAlchemy 2.0**:
  - `select()`, `where()`, `order_by()`, `group_by()`.
  - Executing async queries (`scalars().all()`, `scalar_one_or_none()`).
  - Bulk inserts, updates, and atomic transactions.
- **Database Migrations with Alembic**:
  - Initializing Alembic, configuring `env.py` for async engines and model metadata.
  - Generating auto-migrations (`alembic revision --autogenerate`).
  - Applying and rolling back migrations (`alembic upgrade head`, `alembic downgrade -1`).

#### Assignments:
1. **Product Catalog & Inventory ORM**: Build an asynchronous Python program using SQLAlchemy 2.0 to model Categories, Products, and Tags (Many-to-Many), performing full CRUD operations with `asyncpg`.
2. **Order Management System with Migration Suite**: Design an Orders and LineItems schema, configure Alembic, create initial tables, alter columns with zero data loss, and rollback gracefully.
3. **N+1 Query Eliminator**: Create a script displaying orders and their nested item details; optimize it from 101 separate queries to a single efficient query using `selectinload`.
